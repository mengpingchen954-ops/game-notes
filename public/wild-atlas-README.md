# 万灵秘图 · Wild Atlas

一款可直接在浏览器游玩的 Three.js 2.5D 寻宝冒险。选择旅人，获得游鱼和苍鹰卡牌，躲避自然天敌，拼合局部地图，进入遗迹并开启最终宝箱。

这是一个完整的小型单关游戏：有开始、成长、挑战、失败重试、存档与结局。它不是此前设想的数小时 Steam 正式版。原设计的 15～20 分钟是目标预算，当前实际时长取决于观察、探索和重试，不能把自动化通关时间当作普通玩家时长。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```powershell
cd "C:\Users\chenmengping\Documents\ChatGPT\game designer\wild-atlas"
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:4173/ 。该本地地址只在服务器运行时可用。

已打包的本地版本可以直接双击 `play.cmd`：使用 Node.js 启动静态服务器并打开浏览器，无需先安装 npm 依赖。保持服务器窗口开启。也可运行 `npm start`。

```powershell
npm run build
npm run preview
```

`dist/` 是可部署的静态成品，上传到任意静态 HTTP 托管即可；使用相对资源路径，可部署到子目录。请通过 HTTP 打开，不要双击 `dist/index.html` 使用 `file://`。运行时没有远程字体、素材 CDN 或 API 依赖。

## 操作

| 操作 | 键盘 |
|---|---|
| 移动 | A/D 或左右方向键 |
| 游鱼上下游动 | W/S 或上下方向键 |
| 跳跃／苍鹰起飞 | Space |
| 游鱼冲刺 | Shift |
| 拾取碎片、机关、宝箱 | E |
| 人形／游鱼／苍鹰 | 1 / 2 / 3；也可点击卡牌 |
| 变身轮盘 | 按住 Tab，移动指针选择，松开确认；也可按数字选择 |
| 地图 | M |
| 暂停／关闭菜单 | Esc |
| 苍鹰主动下降 | S；气流内自动上升 |

触屏设备显示方向按钮、起跳、冲刺和互动按钮。手机建议横屏获得更开阔的视野。声音和流畅画面模式在暂停菜单切换。

## 完整流程

1. 营地向右，靠近金色石碑按 E，取得第一块地图与游鱼卡。
2. 浅水岸边按 2，潜入水草，观察鳄鱼；冲刺会产生噪声。绕过水下岩石，靠近右端水面按 1 上岸。
3. 瀑布石室取得第二块地图与苍鹰卡。沿石阶登高，按 3、Space 起飞。
4. 借金色上升气流穿过断崖，在平台歇脚。捕食者鸣叫后会锁定俯冲线，改变高度或落地躲避。
5. 在双峰观察台打开完整地图，对照拱形岩，飞到右方低处河岸。
6. 人形靠近右岸，化鱼进入第二条水道；出口恢复人形，转动日轮，开启宝箱。

变身不消耗卡牌，也无统一倒计时。轮盘、地图和暂停菜单冻结玩法。每次失败返回最新安全检查点，保留卡牌、地图和石门。存档保存在当前浏览器的 localStorage；无权限时会提示并允许继续本次游戏。重新开始需确认覆盖未完成的存档。

## 技术和资源

- `src/simulation.js`：不依赖 DOM 或 Three.js 的游戏状态、平面碰撞、移动、敌人和存档规则。
- `src/render.js`：正交侧视摄像机、Three.js 场景、动画、静态景物合批、粒子与画质。
- `src/art.js`：旅人、动物、遗迹、植被和 Canvas 纹理的程序化美术。
- `src/main.js`：键盘／触屏输入、HUD、菜单、音频事件与固定时间步驱动。
- `src/icons.js`、`public/assets/`：原创 SVG 角色肖像、卡牌图标、指南针和手绘秘图。
- `src/audio.js`：本地 Web Audio 合成的环境和反馈声音，无需下载音频。

运行环境没有可调用的内置 imagegen，因此按用户授权使用程序化模型、Canvas 和 SVG 完成全部美术；没有调用付费图像 API，也没有将这些素材表述为 AI 生成图片。游戏没有武器、战斗或随机升级系统，收集物和卡牌承担成长反馈。

2.5D 规则只在 X/Y 平面计算简单碰撞，Z 用于表现景深；未引入完整 3D 刚体引擎。静态模型按空间与材质合批；几何体和材质复用；粒子使用一个可更新缓冲区；限制像素比；提供降低渲染分辨率并关闭动态阴影的流畅模式。持续低帧率时会自动切换一次，玩家仍可在暂停菜单手动调整。

## 验证

```powershell
npm test
npm run test:browser
```

浏览器测试运行前需启动本地服务器。首次安装 Playwright 后若缺少浏览器，运行 `npx playwright install chromium`。测试使用独立浏览器上下文，不读写用户已有的游戏存档。

- 玩法测试覆盖卡牌领取、存档校验、形态限制、河道碰撞、气流、受击／重生和宝箱条件。
- 浏览器测试以真实键盘和点击完成主线，不注入角色位置或解锁状态，并记录截图、报错和性能数据。
- 测试截图及报告保存在 `tests/evidence/`。
- `window.__WILD_ATLAS__` 提供只读快照与帧率／绘制统计，不提供游戏状态修改功能。

支持现代桌面浏览器的 WebGL 2。触屏已有输入与布局支持；真实手机 GPU、Safari、游戏手柄和 Steam 封装仍需单独验证。
