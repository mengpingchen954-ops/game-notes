# 飞剑，回来！

按黑盒 v4 制作的单人 Three.js 2.5D 浏览器游戏。一个完整的青石庭院关卡：六名敌人、三格生命、投剑／绕位／直线召回、胜败结算与即时重来。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5188/ 。

发布构建：`npm run build`。本地查看发布构建：`npm run preview`，同样使用 5188 端口；先停止开发服务器再启动预览。

`dist/` 可以部署到任意静态站点的根目录或子目录，所有资源均为相对路径。不能直接双击 HTML 使用 file:// 打开，需要 HTTP 服务。没有运行时 CDN、在线字体、账户或服务端依赖。

## 操作

- WASD / 方向键：移动，同时决定角色朝向。
- 空格 / J / 点击场地：持剑时投剑；飞出或插住时召回；返回中忽略重复按键。
- R：立即重来；Esc：暂停 / 继续。
- 触屏：左侧摇杆移动，右侧动作按钮投剑 / 召回。
- 标题页可选男女侠客，仅发型与装饰不同，碰撞、移动和伤害规则完全相同。

出剑不伤敌。召回锁定按键时的玩家位置；剑沿固定直线判伤，到达后无伤害瞬间回手。红衣盾兵只能从背面击中。敌人亮出红色扇形后锁定攻击方向，玩家可以侧移躲避。消灭全部敌人获胜，血量归零失败；没有倒计时。

## 对黑盒未指定细节的实施口径

- 场景采用俯视倾斜正交镜头，人物在地面平面内移动。
- 出剑在场地边界或石柱处停住；回程穿过石柱，避免卡剑。角色和敌人不能穿过石柱。
- 盾兵背面为背向半平面；正侧方临界情况按格挡处理，以飞剑实际进入时的朝向判断。
- 普通追兵、盾兵均为一次有效回程命中倒地。
- 接触敌人本身不扣血；只有完成前摇后、处于实际攻击范围内才扣血。前摇、攻击区域都有可见反馈。
- 玩家速度 4.4 单位/秒，飞出 17，返回 22；追兵 1.45，盾兵 0.95。追兵前摇 0.58 秒，盾兵 0.8 秒。玩家受伤无敌 0.8 秒。
- 开局 1.4 秒准备期，敌人可见、可受伤但尚不追击。
- 胜利与致命受击同一固定步发生时，胜利优先。
- 胜败均可立即按 R 重来。慢镜、粒子、攻击、按键与摇杆状态一并取消。

## 美术与音效

采用暖色青石、青绿衣袍、朱红盾兵和金色饰边。资源由 `src/view.js` 生成并直接接入：

- 有衣袍、束发、衣襟、腰带、四肢和武器的低多边形男女侠客；戴斗笠的追兵、持八角盾的盾兵。
- 青石地砖 Canvas 贴图、八卦纹章、书法旗帜、亭台、月门、竹林、远山与石灯柱。
- 飞剑模型、剑穗、地面朝向标记、锁定路径、攻击预警、碎光粒子与落叶。
- 原创 SVG 剑图标、标题页、HUD、手机触控、帮助、暂停、胜败结算。
- Web Audio 合成投剑、召回、格挡、命中、受伤和结算声音，可静音。

当前环境没有 imagegen 内置工具，使用用户允许的程序化美术替代，没有调用图像 API。核心黑盒不包含升级和掉落物，因此未增加相应系统或无用途图标。

## 验证

```sh
npm test
# 先在另一个终端启动开发或预览服务器：
npm run test:browser
```

- `tests/simulation.test.js`：14 项机制测试，包含锁定点、无伤害回手、盾兵朝向、重复伤害、同时胜负、0.8 秒无敌、重置和固定步可重复性。
- `tests/browser.mjs`：实际键盘驱动清场、失败、重来、暂停、角色选择、触控、视口与控制台检查。只读取状态，不注入战斗结果。
- `artifacts/`：桌面与手机截图、浏览器测试结果。`window.__sword.snapshot()` 为只读诊断入口。

仿真使用固定 60Hz，画面帧率独立。静态网格合批、静态阴影只绘制一次、像素比上限 1.6，慢设备自动降至 0.85。粒子最多 150 个。合成音源使用后释放。

自动化验证证明运行与规则可用，不代表已经证明玩家觉得好玩。当前没有真人重玩数据，也没有跨设备 60FPS 保证。

## 文件

- `src/simulation.js`：独立、可重复的战斗规则。
- `src/view.js`：Three.js 渲染及程序化美术。
- `src/main.js`：界面、输入、音效、生命周期。
- `src/style.css`：桌面和触屏界面。
