# 《天下第一，禁止动武》——百艺擂台大会策划案

版本：V0.2 · 2026-09-28 · 供玩法评审

本轮任务：先确定多项目益智擂台的策划，不修改或发布现有网页游戏。

## 1. 定位与方向

**一句话：在一场禁止动武的武林大会里，靠各种简单操作的益智比赛，赢过一群不肯服输的高手。**

玩家是不擅武功的小人物。盟主宣布本届大会封刀封剑，各门派只能以本事服人。高手纷纷把自己的绝活搬上擂台：摆阵、辨谎、藏珠、称物、取筹、分水。玩家挑赛、解题、拆穿对手的套路，一步步拿到大会头衔。

大会可以荒诞，规则必须讲理。人物负责抓马，输赢必须由玩家看得懂的操作决定。

喜剧方向采用「武林大会办成大型综艺现场」：高手立人设、观众拆台、裁判认真补刀。网络表达改写成与实际玩法有关的场面，例如把“出圈”做成掌门真的走出擂台，把“班味”做成裁判想准时下班。具体人设、24 项包装、六场台词和触发规则独立整理在[网络梗与喜剧包装策划](./no-fighting-humor-design.md)，本文件继续负责玩法与赛制。

现有「放旗—话术—举证」三段式改作一个可保留的专题挑战；后续主线采用**一场一个独立小游戏，多场组成一届大会**。每一场有自己的场面、目标、操作和结算，不要求所有比赛都走棋、对话或交证据。

### 体验目标

- 看一眼知道这场在比什么，操作说明尽量只有一句。
- 常用操作为点击、选中后再点击；拖拽只作可选快捷方式。
- 单场目标时长约 45—120 秒，一届三场约 4—7 分钟，均为待试玩验证的设计目标。
- 主要乐趣是「我看穿了」「原来还可以这样」「他刚吹完牛就被我赢了」。
- 初版面向单人、移动端优先的网页游玩；不依赖联网匹配和快速反应。

## 2. 为什么这些小游戏属于同一个游戏

统一五件事，变化一件事。

| 统一项 | 具体做法 |
| --- | --- |
| 场所 | 同一座武林大会；按项目换上桌案、天平、茶盘、机关架 |
| 身份 | 玩家一直是那个被低估、逐渐成名的参赛者 |
| 对手 | 同一批高手反复登场，有偏好、口头禅和输赢反应 |
| 比赛仪式 | 掀开项目签 → 对手放话 → 裁判演示 → 操作 → 落印 |
| 成长 | 项目记录、对手手册、胜印、头衔，汇入同一本大会战绩 |
| 每场变化 | 操作对象与解题规则；每场只引入一个主要思维任务 |

比如岳不挪既可以参加「请君出圈」，也可以在「抢筹争先」里嘴硬。前一场输了，他会说：“走路让你讨了巧，这回坐着比！”由人物关系串联项目，而不是仅在菜单里罗列游戏图标。

## 3. 主循环与赛制

**看赛签 → 选项目 → 看对手放话和一次演示 → 玩一场 → 看胜负反应 → 选下一场 → 领取大会战绩。**

### 一届三场

1. 开幕教学大会固定三个项目，避免首次选赛的信息负担。
2. 常规大会每轮提供两张项目签，显示玩法类别、目标和难度，玩家选一张。
3. 三场来自不同类别；抽签只从已完成教学的项目中取，不会突然要求学习陌生规则。
4. 一场达成该项目公开目标即获一胜；三场两胜为「本届优胜」，三战全胜为「全胜夺魁」。
5. 即使前两场已两胜或两败，第三场仍可争取个人战绩；玩家也可提前结束本届，未赛场计未胜。
6. 单场未通过时可当场再试一次。第二次仍未通过，则记录未胜并继续下一场；不会堵住大会流程。
7. 练习擂台允许不限次数重试。练习更新单项最好记录，但不改写已结束大会的赛果。

首版不再增加淘汰赛、复杂积分、装备数值或额外决赛。后续长赛程只在三场短赛已有复玩意愿后评估。

### 怎样判定对手输了

- 解谜项目：裁判提前公布局面与有限资源，玩家达成目标，对手承认其招式被破。
- 信息项目：玩家依据公开口供或可用试验，找到唯一答案。
- 轮流项目：玩家与对手按同一套规则行动，以棋局终态判胜。
- 对手台词不改变判定。揭晓时必须回放关键一步，或解释玩家证据对应的事实。
- 避免伪造“对手用了 18 秒”一类成绩。解题赛也不假装双方在实时竞速。

## 4. 24 个项目储备，分为六类

“参考原型”表示可研究的常见规则类型，不代表复刻某一商业游戏的关卡、美术或文字。下列为项目池，首版不会同时制作 24 个项目。

### A. 空间与路线：看懂局面，借位置取胜

### E. 轮流与预判：先看清终局，再落这一手

| --- | --- | --- | --- |
| 抢筹争先 ★ | 每次取一或两根签，取走最后一根者胜 | 算师每次都说“你随意”，直到发现剩数不对 | 取子游戏、逆向推理 |
| 连线占地 | 每回合连一条边，围成一格得分，最终多者胜 | 对手贪吃一格，送出一整片 | 点格棋 |
| 护送掌门 | 交替移动一枚棋子或设置有限路障，先抵终点者胜 | 嘴上说“礼让三分”，手里把路全堵上 | 简化围堵竞走 |
| 分糕留一手 | 玩家切分、对手先选，满足两边公开需求的份数目标 | 贪心的对手先挑，仍只能拿到公平一份 | 分割与选择、公平分配 |

### F. 结构与改规：换一个摆法或看法

| 项目 | 玩家操作与公开目标 | 对手与戏剧点 | 参考原型 |
| --- | --- | --- | --- |
| 七片成剑 | 点选、旋转并放置七巧板，拼满目标轮廓 | 不能拔剑，却能拼一把“剑”赢比剑 | 七巧板 |
| 一签翻盘 | 移动规定数量的签，使错误图式或等式成立 | 对手坚持“绝无可能”，一签就改了结果 | 移签谜题 |
| 榫卯开匣 | 按可移动方向依次抽出木块，释放匣中信物 | 机关师自称万无一失，被顺序拆解 | 顺序解锁、拆卸谜题 |
| 改一字立约 | 在事先列出的有限词块中替换一个，令条款满足公开目标 | 掌门准备的漏洞被反用，裁判逐项核对 | 有限词块的规则逻辑 |

★ 为首版六项。所有项目都应先解决“规则是否好懂、解法是否公平”，再添加思想点题。后续项目仍需独立验证题面、解法及对手策略。

## 5. 首版六项的可执行规则

### 5.1 请君出圈：先送玩家一场容易理解的胜利

- 布置：掌门、旗位、退场口；首题无屏风，只一面旗。
- 规则：掌门看同一行或列的旗，沿直线赴约；到旗边收旗再观察。走到退场口就负。
- 操作：点击出口放旗，再点鸣锣。点击错误位置给方向提示，不扣机会。
- 首题：沿用现有关卡 `(2,3)` 起点、`(6,3)` 出口，旗放出口，四步出界。
- 胜负：模拟走到出口胜；停止在圈内则本次未胜，展示被挡住或缺少下一面旗的原因。
- 变化：一旗直线 → 两旗转弯 → 加一个遮挡区域。只改变路径，不突然增加移动速度要求。
- 高光：掌门踏出界线仍在喊“接招”，裁判直接举牌：“您先下去了。”

### 5.2 三杯藏珠：给玩家换一种脑力任务

- 布置：三个固定杯位，玩家先看到珠子进入哪一杯。
- 规则：杯子只做清楚可见的两两换位，不临时换珠，不利用遮挡偷偷改变答案。
- 操作：点“看好了”，看换位，再点杯子；可以重播本题一次。
- 首题：珠子在左杯；交换左中，再交换中右；最终应点右杯。
- 胜负：点中即胜；点错回放带珠杯的完整轨迹，不以“你反应慢”为失败理由。
- 变化：两次换位 → 三次 → 四次。初版不增加动画速度；减少记忆链混淆是首要调节手段。
- 高光：千手客抬起错误的杯子准备庆祝，发现玩家早就点中了另一个。

### 5.3 谁在说真话：用短口供完成一次真正推断

- 布置：甲、乙、丙三个箱子，只有一个藏印；裁判先说明“以下恰有一句为真”。
- 首题口供：甲：“印在乙箱。”乙：“印不在乙箱。”丙：“印不在甲箱。”
- 操作：点击一个箱子，再点“请开箱”。提交前可切换，不需逐字输入。
- 答案：甲箱。藏在甲时，三句依次为假、真、假；藏在乙或丙时均有两句真，违背条件。
- 胜负：指出唯一满足条件的箱子即胜；揭晓时把每句话的真假同时标亮。
- 变化：先改变箱位与正反陈述，再引入“恰有两句为真”。每题仅三句、每句一个简单命题。
- 高光：最凶的那个人说了真话，笑得最和气的人反而在骗人；人物表情不是答案证据。

### 5.4 一秤识假：给有限行动真正的信息价值

- 布置：三枚外观相同的钱币，其中恰有一枚较轻；天平一次称量机会。
- 操作：先点钱币再点左盘或右盘；两盘放置完成后点“称”。无需精确拖拽。
- 首题解法：称甲与乙。甲轻选甲，乙轻选乙，平衡则选未上秤的丙。
- 胜负：在一次称量后找出假币即胜。假币身份在入场时固定，不能根据玩家选择更改。
- 错误输入：空盘比较、超出盘容量等无效动作先解释，不消耗称量。
- 变化：三枚一次 → 六枚两次 → 九枚两次；始终明确“假币较轻”，不在同档里加入轻重未知。
- 高光：两盘平衡，掌柜松了一口气；玩家拿起没上秤那枚：“恰好，就是它。”

### 5.5 分水不争：每一步都有可见状态

- 布置：容量四勺和三勺的茶壶，水源、弃水碗、目标杯。目标是得到两勺水。
- 规则：水壶只能装满、倒空，或向另一壶倒到源壶空／目标壶满；不允许凭手感停在任意刻度。
- 操作：点源容器，再点目标；所有可用目标高亮。水位和容量同时显示。
- 首题有效序列：`(0,0) → (0,3) → (3,0) → (3,3) → (4,2)`，再把小壶的两勺倒入目标杯。元组顺序为四勺壶、三勺壶。
- 胜负：目标杯恰好两勺胜。错误动作可撤销；第一档不设步数上限，九步仍无进展则主动提供提示。
- 变化：换成不同但可解的容量与目标；在熟悉后把少步骤作为额外精巧印，不能阻止基本获胜。
- 高光：茶师说“没有两勺量杯”；裁判看着水位说：“可他已经倒出来了。”

### 5.6 抢筹争先：让对手真的与你轮流行动

- 布置：桌上七根签，玩家先手，每次取一或两根，取走最后一根者胜。
- 操作：点“取一根”或“取两根”，对手以相同规则行动。
- 首题策略：先取一根，留下六根；之后使每轮双方取签数合计三，最终由玩家取走最后一根。
- 对手：按照当前剩余数计算合法策略，不偷看未提交的操作，不掷骰决定谁赢。必败态按固定偏好选合法行动。
- 教学：在首次对手行动后，用签堆分组示意“试着给他留下三的倍数”，无需在开局讲公式。
- 胜负：取最后一根者胜。玩家可撤销最近一组“自己＋对手”行动，避免只撤回一方造成状态错乱。
- 变化：七根 → 十根 → 改为每次取一至三根；生成题面须保证先手存在获胜策略。
- 高光：算师把签扇摊开正要嘲笑，忽然发现最后一根留给了你。

## 6. 对手设计：性格负责好笑，规则负责公平

| 对手 | 个性与项目偏好 | 胜前放话 | 输后反应 |
| --- | --- | --- | --- |
| 岳不挪 | 好面子；引势、路线 | “我的脚，比你们的嘴还稳。” | 已站到台下，仍拒绝低头看脚 |
| 千手客 | 爱显摆；藏珠、记忆 | “别眨眼——算了，你睁着也没用。” | 反复检查自己的袖口 |
| 钱掌柜 | 精明惜财；称量、配量 | “少一钱，算我输。” | 想把假币偷偷收回，被裁判按住 |
| 白算子 | 自负；取筹、数理 | “你先选，我让你。” | 数了三遍剩签，忽然不说话了 |
| 机关婆婆 | 外冷内热；拼装、拆解 | “乱碰，扣你两块点心。” | 嘴上嫌弃，手里多塞一块点心 |
| 好好先生 | 笑里藏话；口供、改规 | “我这人，从不说假话。” | 被逐句标真假，笑容慢慢消失 |

首版只需三位完整对手，其余作为内容储备。同一人物可主持多个项目；不需要每做一个小游戏就重新制造整套角色资产。

角色的“赖账”用于演出，不推翻玩家已获得的胜利。若有新规则，必须在下一场开局前公开。

## 7. 传统思想怎样进入玩法

| 灵感 | 可以落到哪里 | 不应替代什么 |
| --- | --- | --- |
| 道家、无为与借势 | 改环境，让对手或机关依自身规则行动；不多做无用步骤 | 不等于所有场次都只能“不动” |
| 儒家的礼、信 | 公开约定、履约、分配、让对手体面认输 | 不用答道德选择题替代解谜 |
| 法家的规则意识 | 明确边界、先讲条件、同一事实同一判定 | 不把临时改规则当高难度 |
| 墨家的实用与工巧 | 拼装、结构、可验证的机关解法 | 不把所有机关都宣称为墨家史实 |
| 名家、逻辑与辨名 | 口供、定义、约束一致性 | 不用生僻文字和歧义充当难度 |
| 兵家与纵横思路 | 逆向推断、路线选择、公开行动下的预判 | 不靠读心或随机猜拳决定输赢 |
| 心学的反省与践行 | 先预测，再行动，再回看自己判断在哪里出错 | 不设一个“悟性数值”代替学习 |

这是一套创作灵感映射，不是学术上的唯一归类。同一个小游戏可以有多种思想解读。玩家在结算时可选看一句点题和一段延伸，不读也能完整游玩。人物不以 MBTI 标签作为解题条件。

## 8. 新手引导与难度控制

### 第一次上场的安排

1. 镜头落在擂台，对手只说一句话。
2. 裁判示范一次有效操作，示范不超过一个决策步骤。
3. 玩家亲手做一个必然成功的教学动作，立即看到角色和场景的反应。
4. 再进入一题相近但不直接标答案的正式题。
5. 首届只开放初学档；完赛后解锁选赛与练习。

### 三档题目

- 初学：一个关键判断；提示容易找到；无倒计时。
- 熟手：多一步推理或多一个约束；每次只增加一种复杂度。
- 巧解：同样规则下少一步、少一次试验或发现另一种解法；作为选玩追求。

首次接触每个新项目都要重新做短演示，不能因为玩家大会头衔高就跳过。比赛签预先标难度，不在局中暗中提高难度。

### 失败、撤销、提示

- 没有生命、体力和失败收费。
- 错点或无效操作不消耗尝试，动作执行前明确显示结果类型。
- 路线、分水等状态题支持撤销。称量、开箱等会获得新信息的动作，不能撤销来白拿额外试验；可重开本次尝试。
- 提示按“看哪里 → 用什么规则 → 下一步怎么做”三级提供。
- 看提示也能获胜，精巧记录可注明使用过提示；不羞辱玩家、不锁主线。
- 没做完可退出。初版保存已结算场次，进行中的一场重开，选赛界面明确说明。

## 9. 为什么玩家愿意接着玩

### 一场内：答案和表现都要有反馈

玩家改动局面后，立即看到水位、路线、天平、真假标记等变化。胜利瞬间突出关键动作，再接对手一句反应和裁判落印。重要演出可跳过，不能每次重玩都读一段长文。

### 一届内：有选择，也有一个够近的目标

下一场提供两个不同类别：刚用完空间思维，可以换记忆或推理。战绩永远显示“本届第几场、目前几胜”，玩家知道还差多远能拿到头衔。

### 多届之间：给可见的内容目标

- 项目册：完成、独立解出、发现巧解三种记录；不是无限数值战力。
- 对手册：记录曾在哪个项目赢过谁，解锁对应输后台词。
- 胜印：如“眼明手稳”“滴水不差”“最后一签”，由具体行为获得。
- 头衔：大会常客、百艺新秀等；优先展示经历，不提供解题数值加成。
- 趣味挑战：让白算子连输两种项目，或把同一道题解出两条路线。

后续可增加固定题种子的每日三擂；首版不做排行榜、连续签到惩罚或无限任务。单纯增加题目数不能替代有意思的机制变化。

## 10. 界面与场面要求

每场结构保持稳定：上方是对手名、当前场次和一句目标；中央是擂台道具，占主要空间；下方是本场的少量操作、撤销与提示。

不要把比赛做成一屏说明卡。规则默认只露一句，更多规则可以展开。对话放在角色身边，重点仍是可操作物件。

### 六项的舞台变化

- 引势：俯视擂台、脚步、边线、请战旗。
- 藏珠：正面茶桌、三只大杯、千手客的手与袖子。
- 口供：三个箱子和三名证人，陈述就贴在对应对象附近。
- 称量：天平占画面中心，钱币在下方托盘。
- 分水：茶案与两只壶，容量直接写在壶上，水位清晰变化。
- 取筹：双方相对坐，签堆位于中央，轮到谁由手势和牌子双重提示。

手机不用缩小整张桌面截图。物件命中区域至少约 44 CSS 像素；关键操作在当前视口容易触达；文字和图形同时表达状态，不只靠颜色。键盘操作覆盖选择、确认和退出；提供减少动态效果选项，首版不依赖声音作答。

## 11. 首版范围与开发顺序

### 第一步：验证“这是一场大会”

- 三个差异明显的项目：请君出圈、谁在说真话、抢筹争先。
- 每项三道手工验证的题，共九题；首次接触另有短示范。
- 一套三场赛程、三位对手、明确胜负、重试、结算和本地战绩。
- 先请玩家玩，检查是否想点开下一张赛签。

### 第二步：完成首版六项

- 加入三杯藏珠、一秤识假、分水不争。
- 共六项，每项三道正式题，合计十八题；六个短示范不计入题量。
- 加入两选一赛签、练习擂台、项目记录、胜印和基本对手台词变化。
- 一届内类别不重复；同项目正式题轮换；题库耗尽可以复玩，但不假装是新题。

### 第三步：按实际喜好扩充

根据试玩中的主动重玩、提示需求和误解，挑选后续六项。先扩规则被喜欢的项目，再增加尚未覆盖的操作类型。24 项是储备，不作为首版交付承诺。

### 现有内容怎样处理

- 保留现有教学关作为引势项目的参考和可复用规则。
- 当前三回合对话举证版保留为旧方案原型，独立入口，不再作为所有比赛的模板。
- 复用人物、纸墨配色、裁判落印等素材；比赛界面按道具重组。
- 本文只写策划，不在本轮改变上述线上入口。

## 12. 技术与内容约束

- 网页优先、单人离线可玩；本地记录带版本号，异常时说明存档未能保存。
- 各项目共用比赛入口、结算、提示、声音设置和记录，但各自保有独立的状态及判定函数。
- 抽象边界可包括：载入题面、接收动作、撤销、读取状态、判断终局、解释结果。接口细节交由后续实现设计确定。
- 每份关卡数据必须含题目版本、目标、初始状态、限制、已验证解法、提示和失败解释。
- 题面和对手策略决定后固定；在同一题内不暗改答案。需要随机时记录题种子，便于复现。
- 首版手工题优先；未来程序生成题必须先经过可解性验证，逻辑题另查唯一性，轮流对战题检查先手是否可赢。
- 文案和插画采用自有素材；借鉴通用规则时重新设计题面和表现。

## 13. 验收与试玩计划

以下为验收目标，不是已有测试结果。

### 规则验收

- 所有十八道首版题都有验证过的获胜操作序列。
- 口供题只有一个满足题目条件的答案；不借助人物表情猜真伪。
- 天平的结果与固定的假币位置一致；重试不会临时换轻重。
- 分水始终守恒并遵守容量；取筹双方只能做合法行动。
- 退出、重试、撤销与连点不会重复结算、白拿称量或丢失已结算场次。

### 实际体验

邀请至少五名首次接触的玩家，先观察，不口头代替引导：

1. 能否说出每场目标，并自行完成第一次有效操作？
2. 首场是否多数人能在一分钟左右得到一次明确成功反馈？
3. 输后能否解释为什么输了，知道下一步可以改什么？
4. 三个项目是否被感知为不同玩法，而不是同一套点按钮流程？
5. 本届结束时，是否有人主动选择再开一届或进入练习？

若玩家频繁问“现在到底要点哪”，先改交互；若问“凭什么算我输”，先改规则或解释；若会玩却不想再玩，再调整项目选择、题目变化和角色反馈。

## 14. 主要风险与待定项

| 风险 | 对应措施 |
| --- | --- |
| 只是披武侠皮的小游戏菜单 | 固定三场赛程、复用有性格的对手，让上一场影响下一句台词 |
| 每场都重新学规则，很累 | 同类操作一致；每项目短示范；一届最多三种任务；逐步解锁 |
| 又变得太难 | 初学档先给明确成功；没有手速门槛；提示、撤销、局内再试 |
| 所有比赛都靠猜 | 禁止答案临时变更；每场有可解释解法和必要信息 |
| 太容易，没有复玩理由 | 把基本获胜与巧解挑战分开，增加结构变化和自选难度 |
| 内容量失控 | 三项先验证，六项成首版；十八题全部验解后再扩池 |
| 传统思想变成生硬说教 | 玩法先成立，思想以可选结算点题呈现 |

当前策划暂定：单人、手机优先、轻喜剧、一届三场、不设强制倒计时、首版六项。美术精细度、目标发布渠道及后续商业化尚未决定，均不影响先验证核心玩法。

下一步交接：先由 `plan-production` 将第一步拆成实现与验收任务，再由玩法实现确定统一比赛流程及三个独立项目的边界。当前没有启动新的开发任务，也没有给出未经验证的工期承诺。
