# 《天庭考核：今日宜飞升》——主世界观转向建议

版本：V0.1 · 2026-09-28 · 方向评审稿

## 结论

推荐把“神仙考核”作为整个益智小游戏集合的主世界观。

推荐主标题：**《天庭考核：今日宜飞升》**。

推荐副标题：**神仙不打架，考核见真章。**

现有《天下第一，禁止动武》不必废弃，改成天庭考核中的一科：

> **武德与借势科：请君出圈**

这样，原来的擂台原型成为第一场考试，而不是一款和其他小游戏平行、关系松散的游戏。

## 1. 为什么“神仙考核”更适合

| 维度 | 武林大会 | 神仙考核 |
| --- | --- | --- |
| 多种小游戏的合理性 | 需要解释高手为什么参加藏珠、称量、分水 | 每一项本来就是不同神职的考试 |
| 益智玩法 | 容易被理解成比武的附属项目 | 解题本身就是考核目标 |
| 传统思想 | 作为门派和人物的背景 | 可以变成天庭不同部门的办事原则 |
| 成长 | 赢下一届大会 | 从候补仙吏、见习神仙一路转正、飞升 |
| 喜剧空间 | 高手嘴硬、擂台翻车 | 神仙打卡、绩效、述职、补考、抢编制 |
| 失败处理 | 输掉一场比赛 | “本科目未通过，允许补考，不影响继续报考” |
| 继续扩展 | 需要不断增加新的门派比赛 | 直接增加新的天庭部门和神职 |

最重要的变化是：玩家不再感觉自己在玩六个小游戏，而是在解决六类天庭问题。

## 2. 世界观一句话

天庭编制多年不扩，旧神不退休，新神进不来。玉帝只好启动百年一次的“神职能力考核”。玩家是一个刚拿到临时仙籍的凡人候选人，法力最低，简历最薄，只能靠观察、推理和把事情办明白，争取正式飞升。

天庭的麻烦正好一件接一件：掌门堵在南天门外、真珠混进贡品、判词互相矛盾、龙宫水量对不上、仙官把最后一根签拿走。玩家每过一科，就获得一枚神职印；三枚印可以转正，六枚印可以申请飞升。

这不是“打怪升级”，而是**把一件看似离谱的公务办妥**。

## 3. 核心循环

**签到 → 看考官发难 → 抽取考题 → 玩一个益智小游戏 → 绩效判定 → 听考官嘴硬 → 获得神职印 → 选择下一科。**

每场考试固定四步：

1. **考官放话**：一句夸张的人设台词，告诉玩家这科在考什么。
2. **题面亮相**：只展示当前目标和必要规则，不先讲一页世界观。
3. **玩家解题**：点击、选中、拖动或轮流行动；每科只有一个主要思维任务。
4. **绩效结算**：回放关键动作，给出“通过／补考／巧解”，考官用一句话找台阶。

基础通过不要求完美。少一步、少一次试验或不用提示，才获得“漂亮完成”的额外印。

## 4. 天庭部门与小游戏

首版只做六个部门，每个部门提供一种脑力类型。部门是包装和关卡主题，题目规则仍然写清楚。

| 天庭部门 | 首发科目 | 益智核心 | 部门笑点 |
| --- | --- | --- | --- |
| **南天门秩序司** | 武德与借势科·请君出圈 | 空间、路线、诱导 | 掌门坚持“我只是下台”，其实已经出圈 |
| **千里眼观察司** | 追珠与辨伪科·三杯藏珠 | 观察、记忆、追踪 | 监考官看得太远，反而没看见眼前的珠子 |
| **判官事实司** | 口供一致科·谁在说真话 | 真假、约束、排除 | 申诉理由写得很长，真话只有一句 |
| **财神稽核司** | 金库称量科·一秤识假 | 试验、信息价值 | 账目“轻量化”，赔款不能也轻量化 |
| **龙宫水务司** | 云雨调度科·分水不争 | 容量、状态、步骤 | 号称一碗水端平，结果要求精确到两勺 |
| **太白筹算司** | 天数分配科·抢筹争先 | 轮流、逆向推理 | 考官说不在乎，转身把签数三遍 |

后续部门可以扩展：

- **月老关系司**：配对、排序、承诺与信任。
- **鲁班工造司**：七巧板、榫卯、机关拆解。
- **土地档案司**：时间线、地图和物件归位。
- **愿力规划司**：目标拆解、资源分配、把愿望转成可执行步骤。

## 5. 传统思想如何成为“部门办事风格”

思想不直接变成说明文字，而是变成考题的解法倾向。

| 思想灵感 | 天庭部门化表达 | 玩家实际感受到什么 |
| --- | --- | --- |
| 道家、无为而治 | 顺势司：少动一步，借规则和环境完成目标 | 不乱操作，观察后让局面自己走 |
| 法家 | 天条监察司：条件公开、判定统一、违规可追溯 | 先看规则，再用事实取胜 |
| 儒家 | 礼制与信约司：公开承诺、履约、给人台阶 | 让对方体面地完成约定 |
| 王阳明心学 | 心印司：先想清楚、再行动、再复盘 | 解题不是背答案，而是验证自己的判断 |
| 鬼谷子、纵横 | 游说与使者司：选择话术，改变他人行动 | 不强推对象，利用立场和信息 |
| 墨家 | 工造司：实用、结构、可验证的机关 | 物件怎么动，结果就怎么变 |
| 名家 | 事实司：辨名、定义、真假与条件 | 每句话都必须能对应事实 |
| 吸引力法则的现代改写 | 愿力规划司：把“想要”拆成目标、行动和反馈 | 愿望不是魔法，行动才会改变结果 |

这是一套游戏创作映射，不声称代表这些思想的唯一解释。玩家可以跳过思想解读，只凭规则通关。

## 6. 喜剧语气：古代神仙，现代绩效

核心笑点不是把每句话都塞成热梗，而是让神仙的神性和打工状态同时出现。

### 天庭人事部

太白金星是招聘、考核、补考和转正负责人：

- “法力不是硬指标，能把事办完才是。”
- “这科没过不代表你不优秀，代表这道题对你暂时不够友好。”
- “请勿在考场内释放杀气，影响其他考生松弛感。”
- “补考名额有限，但今天还有空位。”

### 玉帝的年度述职

玉帝不直接考玩家，只在每三场结束时看报表：

- “朕要的是解决问题，不是把问题写成三千字奏折。”
- “谁把‘已读’写进了绩效？”
- “本届飞升名额不多，请各位不要互相内耗。”

### 考官的网络表达改写

| 表达 | 天庭场景 |
| --- | --- |
| 出圈 | 掌门真的跨过南天门边线 |
| 硬控 | 嘴还在输出，脚已经按请战旗的规则行动 |
| 松弛感 | 考官说无所谓，输后偷偷复盘三遍 |
| 班味 | 裁判一边判题一边看散场时间 |
| 情绪价值 | 夸考官可以加气氛，不能替代正确答案 |
| 预制人设 | 神仙提前写好飞升感言，输了只好改成“经验交流” |
| 赛博对账 | 判官把每一步操作与题面条件逐项核对 |
| 活人感 | 一位神仙终于承认自己也会把水倒错 |

现代词只出现在台词和标题里；按钮和规则保持古雅、清楚、直白。

## 7. 第一届“神仙转正考”

第一届不做玩家自由选择，先用三科展示三种完全不同的脑力任务。

### 第一科：武德与借势科

考官：南天门掌门岳不挪。

题目：请把掌门引出边线，禁止碰他。

玩家点击出口放旗，掌门沿路线自己走出圈。

结算：

> 裁判：“恭喜岳掌门，成功出圈。”
>
> 岳不挪：“我说的是成名，不是离场。”

获得：**顺势印**。

### 第二科：事实与口供科

考官：判官事实司。

题目：三名仙吏的口供中，只有一句为真，找出藏印的箱子。

玩家选箱，逐句揭示真假。

结算：

> 判官：“事实不会因为你写了很长的申诉而改变。”

获得：**明辨印**。

### 第三科：天数分配科

考官：太白筹算司的白算子。

题目：七根天签，每回合取一或两根，取走最后一根者通过。

玩家先手，必须逆向看出制胜节奏。

结算：

> 白算子：“我只是让你先。”
>
> 裁判：“您让的是胜局。”

获得：**先机印**。

三科通过后，玩家获得“候补神仙”资格；三科全胜才可参加转正述职。

## 8. 失败与补考

“神仙考核”天然支持宽松的失败设计：

- 初次失败叫“本题未通过”，不叫死亡或淘汰。
- 当场可补考一次；补考会换一句考官台词，不暗改题目答案。
- 仍未通过可以继续下一科，结算显示“本届未转正，欢迎下届再来”。
- 练习模式可以单独重做已解锁科目。
- 使用提示仍可获得基本神职印，但会记录“参考提示完成”；漂亮完成才需要独立解题。

这比“输掉武林大会”更适合轻松益智游戏，也能让玩家愿意尝试不同解法。

## 9. 从旧方案迁移

| 旧内容 | 新世界观名称 | 处理方式 |
| --- | --- | --- |
| 《天下第一，禁止动武》 | 武德与借势科·请君出圈 | 保留棋盘和路线，改标题、考官和结算 |
| 三回合引势／拆招／公议 | 一科内的“题面／答题／复核” | 只在口供或高阶题中复用，不强加给所有科目 |
| 岳不挪 | 南天门秩序司考官 | 保留角色，变成嘴硬的老资格神仙 |
| 胜印 | 神职能力印 | 保留本地收集，显示候补神职方向 |
| 武林大会榜文 | 天庭绩效单 | 记录科目、提示、补考和漂亮完成 |
| 擂台纸墨视觉 | 天庭公文与仙台 | 保留纸墨基调，加金印、卷宗、天门和云案 |

不需要立即重写旧原型代码。先用一张“神仙考核版”的开场和三科流程图验证语气与世界观，再决定是否改线上入口。

## 10. 风险与控制

| 风险 | 控制方式 |
| --- | --- |
| 变成枯燥的公务员考试 | 每科绑定一个正在出问题的天庭事件；考官有明确怪癖和反应 |
| 网络梗过时 | 台词替换成原创的行为笑点；梗只做短标题，不成为规则关键词 |
| 神仙太多、认不住 | 首版只用三位考官、三个部门，其他部门后续解锁 |
| 思想变成说教 | 先玩后点题；解题结果比解释更重要 |
| 玩法仍像菜单集合 | 用候补仙籍、三枚神职印、转正述职串起每一科 |
| 古代和现代语气冲突 | 场景、道具、称谓古风；台词允许现代；操作文本始终清楚 |

## 11. 建议下一步

先做一张完整的“第一届神仙转正考”流程原型：

1. 签到领取临时仙籍。
2. 太白金星用一句话说明考核目标。
3. 连续体验请君出圈、谁在说真话、抢筹争先三科。
4. 每科结算获得顺势印、明辨印、先机印。
5. 通过或未通过都进入“候补仙籍成绩单”。
6. 最后一段开放转正述职的锁定预告。

这一步只验证三件事：玩家是否觉得三科属于同一个世界、是否愿意继续抽下一张考签、现代笑话是否盖过了玩法。验证通过后，再把另外三科和更多思想部门加入。
