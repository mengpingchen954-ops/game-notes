# 《天庭考核：今日宜飞升》玩法机制设计

版本：V0.1 · 2026-09-28

关联：[完整 GDD](./heavenly-exam-gdd.md) · [抓马升级策划](./heavenly-exam-drama-upgrade.md)

## 1. 核心玩法一句话

> **玩家不攻击神仙，而是设置条件，让神仙、机关或规则自己暴露事实；解题赢到的每一份结果，都能变成公开听证的证据。**

这套机制把“很多小游戏”和“神仙悬案”绑在一起：每场小游戏有独立规则，但每场都产生一件可以追查的事实。

## 2. 三层玩法结构

### 第一层：考核解谜

玩家在一个明确的题面中解决问题。题面公开目标、对象、行动限制和判定方式。

这一层的乐趣是：

- 我能不能看懂规则？
- 下一步动哪个对象最有价值？
- 我能否用更少动作完成？

### 第二层：考后取证

解谜完成后，考官会试图解释自己的表现。玩家从两张卷宗卡中选择一张带走：

- **事实卡**：记录实际发生了什么。
- **矛盾卡**：指出考官说法与实际结果哪里不一致。

选择不影响基本过关，但会影响最终公开听证能否闭合证据链。

### 第三层：公开听证

完成三科或六科后，玩家进入终审，把收集到的卷宗放入三个争议位置：

1. 发生了什么？
2. 谁从中获利？
3. 谁隐瞒了事实？

证据链完整，玩家可以揭露神位篡改案；证据不足，也可以凭考核成绩飞升，但结局会留下“天庭还有下一页”的悬念。

## 3. 每场小游戏的统一机制

每个项目必须具备六个固定部分：

| 组成 | 玩家看到的内容 | 设计要求 |
| --- | --- | --- |
| 目标 | 一句话任务 | 不使用隐喻，直接说要找什么、达到什么状态 |
| 初始状态 | 盘面、道具、人物位置 | 同一题每次重开一致 |
| 公开规则 | 2—4 条 | 规则决定结果，不让台词暗改条件 |
| 行动 | 点击、选择、放置、倒水或取签 | 每次操作都能解释对状态的影响 |
| 反馈 | 路线、水位、真假、天平或签堆变化 | 玩家行动后立即可见 |
| 终局 | 通过、未通过、漂亮完成 | 判定可复盘，可说明关键一步 |

### 3.1 玩家行动的四个阶段

1. **观察**：查看对象和规则，不急着点。
2. **设置**：放旗、分币、选杯、选择箱子或安排顺序。
3. **验证**：鸣锣、称量、开箱、倒水或让对手行动。
4. **复盘**：看到结果和理由，决定是否重试或进入取证。

这套阶段结构让不同小游戏有统一的上手方式，同时保留各自的脑力差异。

### 3.2 可逆和不可逆动作

**可逆动作**可以撤销：放旗、倒水、移动拼图、选择尚未提交的箱子。

**获得信息后的动作**不能在同一尝试中撤销：称量、开箱、揭示真伪、让对手完成一轮行动。玩家可以重新开始本题，但不能通过撤销把已经获得的信息变成额外试验。

### 3.3 三档完成结果

- **未通过**：目标未达成，或提交了错误答案。
- **通过**：用合法规则达成目标，可以使用提示和较多动作。
- **漂亮完成**：在已验证的动作、试验或提示限制内达成目标。

漂亮完成是追求，不是进入下一科的门槛。

## 4. 六个小游戏的具体机制

### 4.1 请君出圈：路线诱导机制

**核心动词：** 放置、引导、观察。

**题面：** 掌门位于棋盘格，边界上有退场口，场内可能有屏风。

**玩家资源：** 一至两面请战旗。

**规则：**

1. 掌门只看见同一行或同一列且无遮挡的旗。
2. 他沿直线走向最近的可见旗。
3. 到达旗位后收旗，再重新观察。
4. 进入退场口即通过。

**玩家不是在控制掌门。** 玩家只改变旗的位置；掌门严格按照自己的规则行动。

**反馈：** 视线高亮、路线线段、逐格移动、越界印章。

**漂亮完成：** 用最少旗数让掌门出界。

**取证：**

- 事实卡：掌门沿路线自行越过边线。
- 矛盾卡：掌门宣称“主动下台”，但旧记录把越界定义为离场。

### 4.2 三杯藏珠：追踪机制

**核心动词：** 观察、记忆、定位。

**题面：** 三至五只杯子，珠子进入其中一只，杯子按明确动画交换。

**玩家资源：** 观察次数固定；首次题不限制时间。

**规则：**

1. 珠子只在一个杯子中。
2. 发生的是杯子交换，不是珠子瞬移。
3. 所有交换完整可见；难度通过次数和路线增加。

**操作：** 点击“开始交换”，观看动画，点击最终杯位。

**反馈：** 当前持珠杯在交换过程用极短高亮提示，结束后消失；提交后完整回放。

**漂亮完成：** 不重播、不使用提示并一次选中。

**取证：**

- 事实卡：玩家在完整回放中确认珠子的真实位置。
- 矛盾卡：千里眼说“回放完整”，但记录中确实缺了两秒。

### 4.3 谁在说真话：约束满足机制

**核心动词：** 阅读、假设、排除、验证。

**题面：** 三个箱子、三名证人、三句短口供、一条真假条件。

**玩家资源：** 选择一个箱子；提交前可以反复切换。

**规则：**

1. 题目明确“恰有一句为真”“恰有两句为真”或其他条件。
2. 每句话只包含一个简单命题。
3. 人物外表和语气不构成隐藏线索。

**操作：** 点击箱子，点击开箱。

**反馈：** 提交后逐句显示真／假，并统计满足条件的句数。

**漂亮完成：** 不打开错误箱子，一次提交正确答案。

**取证：**

- 事实卡：逐句真假结果和最终箱位。
- 矛盾卡：判官卷宗曾使用过不同的真假条件。

### 4.4 一秤识假：信息试验机制

**核心动词：** 分组、称量、排除。

**题面：** 若干外观相同钱币，其中一枚较轻；天平有固定称量次数。

**玩家资源：** 钱币、左右盘、称量次数。

**规则：**

1. 假币位置在开局固定。
2. 天平只比较左右两盘总重量。
3. 空盘或超容量是无效操作，不扣次数。
4. 称量后不能撤回已经获得的结果，只能重开本题。

**操作：** 选择钱币，放入左盘或右盘，点击称量。

**反馈：** 天平倾斜或平衡；剩余次数可见。

**漂亮完成：** 在最少称量次数内找到假币。

**取证：**

- 事实卡：天平结果和假币身份。
- 矛盾卡：金库账目少了一枚盖有正式神印的币。

### 4.5 分水不争：状态守恒机制

**核心动词：** 倒入、倒空、规划顺序。

**题面：** 两只容量固定的壶、一个水源、一个弃水处和目标杯。

**玩家资源：** 容器容量与当前水量。

**规则：**

1. 只能装满、倒空或倒到源壶空／目标壶满。
2. 水量守恒。
3. 当前水量和目标水量始终显示。
4. 首档不限制步骤；少步骤属于漂亮完成。

**操作：** 先点源容器，再点目标容器；支持撤销。

**反馈：** 水位实时变化，非法倒水给出原因。

**漂亮完成：** 在目标步数内得到指定水量。

**取证：**

- 事实卡：每一步水量变化和最终目标量。
- 矛盾卡：龙宫调度表中多次出现相同缺口。

### 4.6 抢筹争先：必胜态机制

**核心动词：** 取筹、留数、预判。

**题面：** 桌上有若干天签，玩家和考官轮流行动。

**规则：**

1. 每回合可以取一根或两根。
2. 取走最后一根者通过。
3. 对手按公开规则行动，策略固定，可复盘。
4. 玩家可以撤销最近一组“玩家行动＋对手行动”。

**操作：** 点击取一根或取两根。

**反馈：** 签堆数量、当前回合、建议观察的剩余数。

**漂亮完成：** 从非必胜初始局面中，通过第一步把局面转成自己的必胜节奏。

**取证：**

- 事实卡：双方真实行动序列。
- 矛盾卡：白算子提前知道某个关键剩余数。

## 5. 证据系统：把解谜结果变成剧情推进

### 5.1 证据不是随机掉落

证据由题目结果和剧情条件固定生成，不能因为玩家重新刷题就随机改变。

首版每科完成后提供两张卡，玩家选一张：

- 一张偏“发生了什么”。
- 一张偏“谁的说法有问题”。

玩家可以通过漂亮完成解锁第三张，但第三张是额外材料，不是必需材料。

### 5.2 证据的三种属性

- **事实**：证明一件事发生过。
- **矛盾**：证明两条记录不能同时成立。
- **动机**：说明某个考官可能从中获利。

单张卡不能直接指认凶手。终审至少需要一张事实卡、一张矛盾卡和一张动机卡，才能构成完整指控。

### 5.3 嫌疑簿

嫌疑簿显示考官头像和三种公开标签：

- 有事实牵连。
- 说法矛盾。
- 可能获利。

它不显示隐藏数值，也不直接告诉玩家谁是凶手。玩家通过证据卡自己形成判断。

## 6. 终审机制：三格证据链

终审不是重新做一套大型逻辑题，而是把前三科得到的材料放进三个争议槽位。

### 6.1 三个槽位

1. **事实槽**：这件事确实发生了什么？
2. **责任槽**：谁的记录或说法与事实冲突？
3. **动机槽**：谁有理由希望这件事不被看见？

### 6.2 操作

- 点击一张卷宗，再点击槽位。
- 放错时，判官说明“这张只能证明发生过，不能证明谁负责”。
- 三张槽位全部闭合后，玉帝开启公开听证。
- 证据不足时允许提交“成绩型结论”，玩家仍能拿到考核资格，但不会解锁完整真相结局。

### 6.3 终审结果

| 证据状态 | 结果 |
| --- | --- |
| 只有成绩，无完整证据 | 通过考核，获得普通飞升资格；封神榜缺页仍未解决 |
| 事实＋矛盾 | 公开质询考官，解锁中等结局 |
| 事实＋矛盾＋动机 | 完成神位篡改案，解锁完整结局选择 |
| 完整证据＋漂亮完成记录 | 解锁隐藏“新任监察神”结局 |

## 7. 题目难度如何递进

每一科的难度只增加一个变量：

| 难度 | 变化方式 | 不增加的东西 |
| --- | --- | --- |
| 初学 | 对象少、目标明显、提示直接 | 不增加倒计时、不隐藏规则 |
| 熟手 | 增加一个对象或一个限制 | 不同时加入两种新机制 |
| 巧解 | 减少步骤、减少试验、要求漂亮完成 | 不把基础答案变成唯一竞速 |

### 7.1 举例：请君出圈

1. 一面旗放出口。
2. 两面旗需要考虑先后和遮挡。
3. 屏风改变可见路线。
4. 巧解要求使用更少旗或更短路径。

### 7.2 举例：一秤识假

1. 三币一次称量。
2. 六币两次称量。
3. 九币两次称量。
4. 巧解要求不浪费任何称量机会。

每次升级只引入一种新思维，不把题目变成知识竞赛。

## 8. 玩家为什么会持续玩

### 单局内

- 每次操作立即改变状态。
- 失败能说明是哪条规则导致。
- 通过后发现一条新卷宗。
- 考官的解释和事实出现反差。

### 一届内

- 三科产生三种不同思维体验。
- 科目之间的证据会在终审汇合。
- 之前的选择会改变最后拿到哪张卷宗。

### 多届之间

- 重新挑战漂亮完成。
- 收集不同部门的神职印。
- 选择不同证据，解锁不同考官反应。
- 补齐完整嫌疑簿。
- 追求不使用提示的成绩单。

## 9. 实现时必须守住的规则

- 正式判定和演示、预览使用同一纯模型。
- 同一道题重试时初始状态和答案不变。
- 考官可以撒谎，规则文本不能撒谎。
- 证据由真实游戏事件产生，不能为了剧情凭空掉落。
- 玩家不需要读完剧情才能通关小游戏。
- 抓马不通过突然死亡、强制背叛或临时改规则制造。
- 失败允许补考，基本通关与完整调查分开。

## 10. 最小可玩验证范围

第一版只实现：

1. 天庭考核大厅。
2. 请君出圈、谁在说真话、抢筹争先三科。
3. 每科一题教学、一题正式。
4. 每科两张取证卡，三格证据链。
5. 一段“封神榜缺页”的终审预告。

验收问题只有三个：

- 玩家是否能独立完成三个不同类型的小游戏？
- 玩家是否理解三科属于同一个天庭事件？
- 玩家是否想知道“谁把神位改没了”？
