# 《天下第一，禁止动武》——网络梗与喜剧包装策划

版本：V0.1 · 2026-09-28 · 策划草案，未实装

关联：[百艺擂台大会主策划](./no-fighting-tournament-gdd.md)

## 1. 创意方向

**你负责赢比赛，他们负责维持快要崩掉的人设。**

大会主标题继续使用《天下第一，禁止动武》。对外介绍可用：“武功暂且不论，嘴是真的硬。”选赛页标语可用：“各凭本事，也各有说法。”

讨论过的三个方向：

| 方向 | 乐趣 | 局限 |
| --- | --- | --- |
| 江湖职场 | 打卡、加班、甩锅、门派考核 | 全部角色都说职场话，容易单调 |
| 离谱武林综艺 | 登场放话、观众拆台、赛后采访、人设翻车 | 演出过长会打断解谜 |
| 无厘头江湖 | 物件误用、名字谐音、一本正经说荒唐话 | 规则容易被笑话盖住 |

推荐以「武林综艺」组织场面，裁判承接职场笑点，少量无厘头负责意外。古装道具、说书腔和现代社交心理混搭。角色不必每句话都塞网络词，能让人会心一笑的具体动作优先。

## 2. 开场样稿

大会旗帜落下：**天下第一武林大会——本届禁止动武。**

掌门：“武林大会不许动武，那比什么？”

裁判摊开去年的账本：“比谁今年不用报销医药费。”

旁边弟子小声问：“奖杯是真的吗？”

钱掌柜：“荣誉是真的。杯子请勿火烧。”

主持转向玩家：“这位少侠，有何绝学？”

玩家可任选一句回答，仅决定一小段回应，不影响难度：

- “我来吃席的。”主持：“正好，缺个参赛的。赢了加菜。”
- “我只会一点点。”主持：“够了，上一个只会自我介绍。”
- “我师父让我见见世面。”主持：“来得正好，台上几位也没见过。”

随后立刻进入可操作的第一场。开场可跳过，重玩不强制重播。

## 3. 网络表达怎样转成游戏笑点

| 表达或喜剧母题 | 江湖改写 | 必须对应的实际场面 |
| --- | --- | --- |
| 出圈 | “掌门今年终于出圈了。” | 对手真的跨过擂台边线 |
| 班味 | “申诉可以，别卡着散场提。” | 裁判在场间整理判词、准备收工 |
| 松弛感 | “胜负乃身外之物。”说完偷偷数签三遍 | 输给玩家后重数，不改变已公布结果 |
| 硬控 | “嘴还在输出，脚已经听旗的了。” | 掌门沿可见路线赴约，不是假称玩家被控制 |
| 情绪价值 | “夸您三句算赠品，奖杯不能赠。” | 场间采访或结算；胜负不由讨好决定 |
| 嘴硬 | 嘴上说没认真，手里把复盘纸写满 | 对手输了以后的动作 |
| 预制人设 | 赛前写好获奖感言，赛后划掉“获奖”改成“交流” | 胜负揭晓后根据真实结果切换纸条 |
| 已读乱回 | 问宝物在哪，对方先夸你年轻有为 | 开题前闲聊；正式口供仍短且无歧义 |
| 含金量 | “含金量多少，咱们上秤说。” | 找出较轻假币；不把“轻”当成真实金属鉴定知识 |
| 社交体面 | 对手请求：“赢可以，能不能别当着我徒弟？” | 场间台词，不增加放水条件 |
| 搭子 | “找个能赢的参赛搭子，我负责上台。” | 后续双人角色包装储备；首版仍单人 |
| 红温 | 掌门扇子越扇越快，嘴上坚持“天气热” | 玩家反转成功后的角色演出，非隐藏怒气数值 |

“预制高手”“情绪价值不兑换奖杯”等为本作改写；不宣称它们是现成热梗。上述表达中有多年使用的说法，也有近年流行语，不把整张表标成“2026 最新热梗”。

## 4. 六位人物的喜剧分工

### 岳不挪：嘴硬型掌门

他最在乎徒弟有没有看见自己输。同一句“我没认真”，会在不同结果下配不同动作。

- 登场：“赢我？你先让我挪半步再说。”
- 出界：“我是主动下来的。”
- 裁判：“自愿的，更好记。”
- 再遇玩家：“这次把台子加宽。谁说我是因为上次？”

### 千手客：表演欲很强的藏珠高手

他把演出排得很好，唯独没安排自己输。

- 登场：“看不清很正常，我自己都快看不清了。”
- 玩家点中：“你刚才是不是只看珠子，没看我的手法？”
- 观众：“不然看您袖口洗没洗？”
- 玩家没点中：“看，还是得看手法。”裁判：“先回放珠子在哪。”

### 白算子：努力表现得很松弛

他说随便，实际每一步都在算。喜剧来自他的姿态与小动作。

- 登场：“你随意，我都行。”
- 玩家走出制胜一步：“你这个随意，是不是提前想过？”
- 输后：“胜负不重要。签别收，我再数一遍。”

### 钱掌柜：把一切算成成本

- 登场：“感情可以谈，损耗另算。”
- 假币揭晓：“它轻，是因为不想给各位增加负担。”
- 裁判：“请它先给您的赔款增加一点重量。”

### 机关婆婆：刀子嘴，认真教人

她的笑点照顾新手，失败时给玩家台阶。

- 玩家迟疑：“机关又不下班，你慢慢想。”
- 玩家失败：“手没事就行，木头比你便宜。”
- 玩家成功：“也就那样。”随后悄悄把玩家的解法抄进自己的本子。

### 打工裁判：全场最讲道理，也最想收工

- 开场：“本届禁止动武。也请各位禁止把规则听一半。”
- 对手赖账：“面子本会不判，边线本会看得见。”
- 判决：“申诉已收到。理由与上次相同，结果也一样。”
- 收场：“冠军领印，其他人领走自己。桌上的笔留下。”

所有人物的笑点都来自虚构性格和实际行为。玩家首次失败时，优先给解释与鼓励，不触发围观嘲讽。

## 5. 首版六场的完整喜剧节拍

每场采用「先吹一句 → 玩家亲手造成反差 → 最后补一句」。一场只选一个主要笑点，不连续把所有备用台词都播出来。

### 5.1 请君出圈｜本场小标题：掌门终于出圈了

1. 开赛，徒弟举牌：“助力师父出圈！”
2. 岳不挪：“站在台上，才能让江湖看见我。”
3. 玩家在出口放旗，掌门沿路线赴约；关键动作完整可见。
4. 他踏出边线，徒弟低头看牌，再看师父，默默把感叹号改成问号。
5. 裁判：“恭喜，已经出圈。”掌门：“我说的不是这个圈！”

实际规则仍是“放旗，引导掌门走到退场口”。字幕在移动结束后出现，不能遮挡出口。失败时不播放出圈庆祝。

### 5.2 三杯藏珠｜本场小标题：手法很满，珠子很诚实

1. 千手客：“这招练了二十年，一般人跟不上。”
2. 裁判：“一般人只要找珠子，不用跟您学二十年。”
3. 玩家观察杯子移动并选杯，观察阶段安静呈现轨迹。
4. 选对揭晓，千手客压低声音：“这段能剪掉吗？”
5. 观众：“不能，我刚看懂。”

选错时显示真实轨迹，裁判说：“刚才走哪儿了，我们慢放一次。”不出现“手残”“眼瞎”等羞辱。

### 5.3 谁在说真话｜本场小标题：话都挺满，真话限量

1. 三名证人齐声：“我这个人最讲诚信。”
2. 裁判翻卷宗：“很好，接下来三句话，只有一句是真的。”
3. 玩家读短口供、选箱；人物闲话停止，题面不夹笑话。
4. 答案揭晓，真假标记逐一盖下。
5. 说假话的证人：“我主要是提供情绪价值。”裁判：“本场暂不收这个。”

笑话在已验证的逻辑题之外，不用“可能在”“大概没说谎”等含糊表达改变约束。

### 5.4 一秤识假｜本场小标题：含金量，上秤再说

1. 钱掌柜：“本店信誉，重如泰山。”
2. 玩家分币、称量、找出较轻假币。
3. 掌柜立刻解释：“这是轻量化款。”
4. 裁判：“足重的钱，您收的也是轻量化价吗？”

天平必须先给清楚的平衡或倾斜结果。真假由关卡数据决定，不因一句台词临时换币。

### 5.5 分水不争｜本场小标题：端水大师，精确到勺

1. 茶师：“我做人，最讲究一碗水端平。”
2. 裁判：“那请量两勺。”茶师看了看四勺壶和三勺壶：“非要这么具体？”
3. 玩家倒水得到目标量；水位、容量、有效动作完整显示。
4. 茶师：“少侠情商很高。”
5. 裁判：“这回主要是算得好。”

选赛签仍明确写“量出两勺水”。“端水”只是语气包装，不能误导玩家以为目标是两边平均。

### 5.6 抢筹争先｜本场小标题：嘴上随便，心里重算

1. 白算子端着茶：“你随便取，我不在乎。”
2. 玩家留下制胜的剩签数，白算子把茶放下。
3. 下一手后，他把扇子合上。
4. 玩家取走最后一根，白算子：“我真的不在乎。”同时把签重新排了三遍。
5. 裁判：“结果已记。您可以继续表现不在乎。”

对手在局面确定进入必败态时才触发放茶动作，不能只因玩家点了一次按钮就假装被算计。

| 护送掌门 | 礼让三分，路堵七分 | “说好的请便，怎么哪儿都不便？” |
| 分糕留一手 | 格局打开，糕点留下 | “你先选可以，便宜未必先占。” |
| 七片成剑 | 剑没开刃，脑子开了 | “剑拼好了。拔剑环节因赛规取消。” |
| 一签翻盘 | 别动我，让我动一根 | “对手准备了三页辩词，你只动了一根。” |
| 榫卯开匣 | 机关的班，今天上到这 | “拆的是机关，破的是机关师的防。” |
| 改一字立约 | 合同不长，心眼不少 | “读完了小字，掌门开始说大话。” |

强情境句必须有对应条件。例如“拿一格、少一片”只在确有连锁失分时使用，不能对普通获胜乱播。条件不足时用不含战绩事实的通用句。

## 7. 喜剧也要随玩家行为变化

### 行为触发

| 真实事件 | 可以出现的回应 | 不能暗示的事情 |
| --- | --- | --- |
| 初次独立解出 | 对手翻看自己预写的获奖感言，把“获奖”划掉 | 不伪造玩家从未看过提示的记录 |
| 使用提示后解出 | 婆婆：“肯问就行，江湖不查闭卷。” | 不扣基本胜利或羞辱求助 |
| 重试后成功 | 裁判：“第一回合是你认识机关，这回机关认识你了。” | 不掩盖赛制记录；重试规则仍按主策划执行 |
| 同一对手在两个项目都败过 | 对手问：“你报名是不是专门填了我的名字？” | 无对应历史就不播此句 |
| 玩家主动重玩已通关题 | 对手：“不是，你还带返场的？” | 不暗示玩家被迫刷任务 |
| 完成较少步骤的已验证解法 | 观众举“刚看懂就结束了”的牌子 | 没有有效步数基准就不称最优 |

首版台词按条件从人工句库选取，不需要联网生成。不向玩家展示“怒气+20”“人设崩塌值”之类额外数值；角色动作足够表达反应。

### 场边观众

以三名固定观众承担短评：懂行的解释关键点、爱起哄的拆台、带徒弟来的替高手找补。每个关键事件最多一句，出现在固定边栏或物件以外区域。

不制作满屏滚动文字，不在藏珠等观察阶段插话。所有观众台词都是剧情演出，不假装来自真实在线玩家。

### 大会榜文

结算可以生成一张可保存的榜文，按实际成绩写标题，玩家自行保存或分享：

- 出圈项目胜利：“某掌门亲自下场，亲自出圈。”
- 称量成功：“少侠一秤落定，钱庄连夜修改宣传语。”
- 三战全胜：“报名时说会一点，领奖时一点没让。”
- 完赛但未优胜：“头衔下次再拿，席今天照吃。”

榜文展示对应项目和真实赛果；本轮只设计，不实现图片导出或自动发布。

## 8. 使用节奏与可替换文案

- 一场开局至多两句，胜负后至多两句；同一时刻只呈现一个笑点。
- 规则、目标、有效动作按钮保持直白，例如“取两根”“确认开箱”“再试一次”。幽默放在旁白与小标题。
- 同一对手准备若干开场、胜利、失败和再遇台词；本届内避免重复同一句。
- 第一次以清楚为主，熟悉后再增加短回调；玩家可跳过台词和关闭观众短评。
- 热词可替换，笑点结构保留。例如“预制人设”不流行后，赛前写获奖感言、赛后改字的动作仍能成立。
- 历史思想留在玩法灵感和可选结算解释中；不伪造孔子、老子或王阳明说过这些网络台词。

## 9. 首版制作范围

先为三位首发角色配齐基础台词和反应，再给六项首发玩法各做一段“放话—反转—补刀”。配套内容包括：

1. 一段可跳过的开场。
2. 六项比赛的清晰名称与幽默小标题。
3. 根据胜负、提示、重试触发的短句。
4. 两至三个低成本角色动作，如放茶、合扇、收牌。
5. 普通获胜、巧解与未获胜都能成立的结算文案。

不为每个笑点新增复杂系统。先用静态分镜或简短演出测试台词是否自然，再交由界面与美术设计安排站位、文字出现区域和动作节奏。

## 10. 评审标准

- 不认识原梗的玩家，仍能看懂发生了什么。
- 把热词拿掉，人物动机和反差依旧成立。
- 玩家笑过之后，仍能准确说出本场目标和输赢原因。
- 笑点指向虚构高手的自负、夸口或矛盾，不围攻玩家的失败。
- 连玩三场没有同一句高频口头禅轰炸。
- 看过一次的演出可跳过，不强迫熟练玩家等待。
- 先评审六场的实际分镜与反应，再决定哪些网络表达值得长期保留。
