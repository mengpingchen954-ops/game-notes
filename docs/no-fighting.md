# 天下第一，禁止动武 · 网页原型

已选方向：《天下第一，禁止动武》。当前提供一关教学局和一场三回合完整比赛；教学局用于第一次上手，完整比赛用于验证核心循环。

## 体验与规则

玩家是不会武功的门派杂役。默认教学局先用一面旗让爱面子的掌门岳不挪自己走出界线；完整比赛再连续经历引势、拆招、公议三回合，用话术、证据和声望赢下裁判。一次局内操作为点击格子、话术或证据牌，支持触屏和键盘，不需要手速。规则通过行动后果表达观察、借势与调动的设计灵感，不作为完整哲学学说的模拟。

- 棋盘坐标以零为起点，掌门从 `(2, 3)` 出发。
- 教学局没有屏风，唯一的退场口在 `(6, 3)`，把旗插到发亮目标即可获胜。
- 进阶局的屏风在 `(4, 2)`、`(4, 3)`、`(4, 4)`；退场口在 `(6, 1)` 和 `(6, 5)`。掌门只看见横排或竖列上不被屏风挡住的旗；沿直线行走，不自动寻路绕障碍。
- 同时看见多旗，先走最近的一面；距离相同按放置顺序。
- 到旗位即收旗，再观察下一面。进入退场口获胜，否则停步并解释原因。
- 进阶局两条通关路线分别为 `(2, 1) → (6, 1)` 与 `(2, 5) → (6, 5)`，均走六步。
- 推演与正式开局调用同一个纯函数，结果一致。支持撤销、重置、中断行走、渐进提示和结算回看。
- 完整比赛入口为 `play/no-fighting/full.html`，三回合共享“势、名、心”状态，并根据话术与证据组合给出不同结算。

## 实现边界

- 独立入口：`play/no-fighting/index.html`。使用 Vite 多页面构建，游戏与笔记站分开加载。
- Phaser 3.90 Canvas 场景；HTML 承载文字、按钮、键盘可访问的格子和结算窗口。
- `src/no-fighting/model.js` 负责确定性规则；`scene.js` 负责场景和行走动画；`main.js` 负责输入与流程；`style.css` 负责纸墨色界面。
- 调色：米纸 `#eee8da`、墨绿 `#29362f`、朱红 `#a83e30`；固定俯视棋盘；桌面左右布局，手机上下布局。
- 当前无可调用的图像生成工具，使用原创 SVG 掌门、观众、请战旗与屏风，以及 Canvas 绘制的院落。此为首版有意采用的矢量美术方案，不声称使用了生成图或经用户审批的概念图。
- SVG 保持独立资产文件，避免 Vite 内联 URL 与 Phaser SVG 加载方式冲突。
- 音效由 Web Audio 合成，默认关闭；无账号、后台、遥测或存档服务。
- 不做真实物理碰撞、战斗养成、随机命中、倒计时与额外关卡。

## 验证与下一步

运行 `npm test` 和 `npm run build`。规则测试覆盖教学局一面旗胜利、遮挡、直线视野、进阶双路线、优先级、无效布局，以及所有合法双旗布局的逐步行走不变量。浏览器测试验证教学局、进阶局、推演、胜利、重开、中断和手机交互。

试玩时观察：玩家是否理解“让对手自己行动”、是否愿意换话术和证据重玩、是否能说出自己赢的是局面、认同还是规则。后续再增加更多对手差异与戏剧事件。
