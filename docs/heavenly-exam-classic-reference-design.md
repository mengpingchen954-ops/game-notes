# 《天庭考核：今日宜飞升》经典益智玩法借鉴与落地规则

版本：V0.1 · 2026-09-28

关联：[最终整合策划](./heavenly-exam-master-plan.md) · [玩法机制设计](./heavenly-exam-mechanics.md)

## 1. 先把“借鉴”说清楚

可以直接借鉴已经被玩家验证过的**底层玩法机制**：推箱、三杯追踪、真假推理、天平称量、倒水、取子、拼图、证据对质。

实际制作时应重新设计题面、关卡布局、角色、文字、图像、音效和代码。照搬某款游戏的关卡排列、素材、对白、UI、角色或源代码，会让作品失去自己的内容，也可能产生版权问题。

本文件的目标是：让程序员和美术拿到后，能按规则直接做第一个可玩版本。

## 2. 统一原型格式

每科原型只需要写清楚七件事：

1. 盘面长什么样。
2. 玩家能点哪些东西。
3. 一次操作改变什么。
4. 玩家看到什么反馈。
5. 什么条件算胜利。
6. 什么情况算失败。
7. 通过后掉哪一张卷宗。

所有题目采用确定性规则。重开同一题，答案和初始状态保持一致。

## 3. 首版六科：直接可做的规则卡

### 3.1 请君出圈

**参考机制：** 轻量 Sokoban 的位置规划 + 《Into the Breach》的敌方行动预览。

**保留内容：** 玩家不直接控制掌门，而是改变他会响应的目标。

**盘面：** 7×7 格棋盘；中间是掌门；边缘有退场口；部分格子是屏风。

**玩家操作：**

- 点击一个合法格子放置请战旗。
- 再点击已放旗子收回。
- 点击“推演路线”显示掌门接下来每一步。
- 点击“鸣锣”正式执行。

**行动规则：**

```text
寻找同一行或同一列中无遮挡的旗
→ 选择距离最近的旗
→ 沿直线移动
→ 到旗位收旗
→ 重新寻找下一面旗
→ 进入退场口则胜利
```

**初级题：** 掌门在 `(2,3)`，出口在 `(6,3)`，只需在出口放一面旗。

**熟手题：** 中间加入屏风，必须先把掌门引到上排或下排。

**巧解题：** 只允许一面旗，玩家必须找到唯一可见路线。

**失败：** 没有可见旗、掌门停在场内、旗位被屏风挡住。

**卷宗：** 边线实际记录。

**为什么好玩：** 玩家先预测、再布置、再看敌人自己走；反馈类似《Into the Breach》那种“我已经看见后果，再决定要不要提交”。

### 3.2 三杯藏珠

**参考机制：** 经典 Shell Game、记忆追踪和《Papers, Please》式的“观察后确认”。

**盘面：** 3 只大杯，珠子从入场到最终位置全程可见。

**玩家操作：**

- 点击“开始交换”。
- 观看两只杯子交换。
- 交换结束后点击一只杯子。
- 点击“慢放回看”消耗一次提示机会。

**行动规则：**

- 杯子交换位置，珠子跟随杯子。
- 不允许杯子重叠后隐藏交换。
- 不允许在玩家看不见的时间偷偷换珠。

**初级题：** 2 次交换。

**熟手题：** 4 次交换，加入同样外观的空杯。

**巧解题：** 不使用慢放，一次点中。

**失败：** 点错杯子。系统立刻播放带轨迹的回放，告诉玩家珠子在哪一步转移。

**卷宗：** 缺失回放的一段记录。

**为什么好玩：** 这是玩家一眼就知道怎么玩的经典追踪玩法，难度可以通过交换次数平滑增加，不需要额外解释世界观。

### 3.3 谁在说真话

**参考机制：** 《The Case of the Golden Idol》的证据推断、《逆转裁判》的矛盾指认、经典真话假话题。

**盘面：** 3 个箱子、3 名证人、3 句话、1 条真假条件。

**玩家操作：**

- 点击一句口供，将它标记为“假设真”或“假设假”。
- 点击箱子查看当前推理结果。
- 点击“提交推断”。

**示例题：**

```text
甲：印在乙箱。
乙：印不在乙箱。
丙：印不在甲箱。
条件：恰有一句为真。
```

答案是甲箱。系统提交后逐句盖章：假、真、假。

**初级题：** 3 人、3 箱、1 条条件。

**熟手题：** 加入“某人和另一人真假相同／相反”。

**巧解题：** 不打开错误箱子，直接一次提交。

**失败：** 选错箱；系统说明哪几句导致真假数量不满足条件。

**卷宗：** 题面曾经被改成“至少一句为真”的版本。

**为什么好玩：** 玩家不是猜谁表情可疑，而是像办案游戏一样，把陈述和事实逐项对上。

### 3.4 一秤识假

**参考机制：** 经典假币天平问题、《Professor Layton》式短逻辑题、《Papers, Please》式逐项检查。

**盘面：** 钱币、左盘、右盘、剩余称量次数。

**玩家操作：**

- 点击钱币选中。
- 点击左盘或右盘放置。
- 点击钱币收回。
- 点击“称量”。

**行动规则：**

- 左右盘总重量相等则天平平衡。
- 较轻一侧说明假币在该侧。
- 假币位置开局固定，不能因玩家选择改变。
- 已完成称量不能撤销，只能重开题目。

**初级题：** 3 枚钱币、1 次称量、假币较轻。

**熟手题：** 6 枚钱币、2 次称量。

**巧解题：** 不浪费称量，第一次分组就缩小到唯一答案。

**失败：** 次数用完仍有多枚候选；系统回放每次称量排除了哪些钱币。

**卷宗：** 缺失的正式神印钱币。

**为什么好玩：** 每次称量都产生信息，玩家会明显感觉到“这一手有价值”。

### 3.5 分水不争

**参考机制：** 经典水壶容量题、《The Witness》式状态观察和《The Room》式直接操作。

**盘面：** 4 勺壶、3 勺壶、水源、弃水碗、目标杯；容器旁显示当前／最大容量。

**玩家操作：**

- 先点击源容器。
- 再点击目标容器。
- 允许装满、倒空、互倒。
- 点击撤销回退普通倒水。

**行动规则：**

- 倒水直到源容器为空或目标容器装满。
- 水量始终守恒。
- 目标杯达到指定容量即胜。

**初级题：** 4 勺壶和 3 勺壶，得到 2 勺。

**示例解法：**

```text
4 勺壶装满 → 倒入 3 勺壶 → 倒空 3 勺壶
→ 把 4 勺壶剩下的 1 勺倒入 3 勺壶
→ 4 勺壶再装满 → 倒入 3 勺壶
→ 4 勺壶剩 2 勺
```

**熟手题：** 更换容量和目标。

**巧解题：** 用少于标准步数完成。

**失败：** 合法操作后仍未达到目标；系统显示与目标相差多少。

**卷宗：** 龙宫调度表里的固定缺口。

**为什么好玩：** 玩家能直接看见状态变化，适合触屏，不需要输入数字。

### 3.6 抢筹争先

**参考机制：** Nim／取子游戏、《Into the Breach》的预判思路和轻量轮流棋。

**盘面：** 中央一堆 7 根天签，左右显示玩家和白算子的座位，顶部显示轮到谁。

**玩家操作：** 点击“取一根”或“取两根”。

**行动规则：**

- 每轮只能取 1 或 2 根。
- 取到最后一根者获胜。
- 玩家先手。
- 白算子按固定策略行动。

**初级题：** 7 根。玩家第一步取 1 根，之后保持双方每轮合计取 3 根。

**熟手题：** 10 根，仍然只能取 1 或 2 根。

**巧解题：** 从较复杂起始数量中判断是否存在先手必胜。

**失败：** 玩家把必胜数量留给白算子；系统回放哪一步把局面交出去了。

**卷宗：** 白算子提前掌握考题的线索。

**为什么好玩：** 规则只有两句话，但玩家会自然学习“不要只看这一手，要看剩几根”。

## 4. 后续可直接借鉴的经典机制

| 天庭科目 | 可借鉴的经典机制 | 天庭改写 |
| --- | --- | --- |
| 规则改写司 | 《Baba Is You》文字规则推移 | 推动“水往东流”“掌门听旗”等词块，改变局面规则 |
| 机关工造司 | 《The Room》旋钮、锁、隐藏机关 | 旋转榫卯、按顺序抽木块，打开封神匣 |
| 视觉拼接司 | 《Gorogoa》画面拼接 | 移动云层、卷轴和门框，让两个场景对齐 |
| 档案监察司 | 《Papers, Please》文件核对 | 对比仙籍、印章、日期和签名，找出不一致 |
| 时间复盘司 | 《The Case of the Golden Idol》事件重建 | 按人物、地点、道具重建一场神仙事故 |
| 路线机关司 | Sokoban／滑块逃脱 | 推动鼎、屏风和箱子，让天门出口露出 |
| 连接阵法司 | 《The Witness》线条谜题 | 按区域、奇偶和封闭条件画出阵线 |

## 5. “抓马”如何嵌进经典机制

抓马只负责改变题面的语境、考官反应和证据，不改变经典机制的公平性。

| 经典机制 | 表面考题 | 背后爆料 |
| --- | --- | --- |
| 推旗路线 | 让掌门出圈 | 他过去的离场记录是假的 |
| 三杯追踪 | 找到宝珠 | 回放被人剪掉了两秒 |
| 真假推理 | 找到正确箱子 | 题目条件版本被改过 |
| 天平称量 | 找到假币 | 神位印被混进金库账目 |
| 水壶容量 | 量出两勺水 | 龙宫长期挪用雨水 |
| 取子博弈 | 取走最后一根签 | 考题提前泄露 |

玩家先用经典规则得到一个确定结果，再看到神仙如何解释这个结果。顺序必须保持：

```text
先解题 → 再发现矛盾 → 最后取证
```

不能让玩家靠“剧情怀疑”直接猜答案。

## 6. 首版最小实现

### 第一阶段：三科验证

只做三个成熟玩法：

1. **请君出圈**：路线诱导。
2. **谁在说真话**：真假推理。
3. **抢筹争先**：取子博弈。

每科包含：

- 1 道必过教学题。
- 2 道正式题。
- 1 次失败回放。
- 2 张取证卡。
- 1 段考官找台阶台词。

三科结束后显示三格证据链和“公开听证即将开始”。

### 第二阶段：补齐六科

加入三杯藏珠、一秤识假、分水不争，复用同一考核大厅、成绩单、卷宗和结算组件。

### 第三阶段：加入高识别度机制

优先选择规则改写、档案核对和机关拆解，因为它们与天庭悬案的“改规则、改记录、藏机关”天然相连。

## 7. 机制验收标准

- 玩家看完目标和三条规则后，能自己完成首个合法动作。
- 每个小游戏的操作都能在 1—2 句话内说明。
- 玩家失败时能看到具体是哪条规则导致失败。
- 规则在题目进行中不会突然改变。
- 考官台词不会替代答案，证据不会凭空生成。
- 六个小游戏的主要思维任务明显不同。
- 玩家即使跳过剧情，也能完成小游戏；看完剧情，会更想知道下一科。

## 8. 参考边界

借鉴的是公开可识别的游戏机制和益智题型。制作时重新编写题面、关卡排列、台词、视觉资产、角色设定和实现代码。保留“天庭考核、考官甩锅、封神榜缺页、解题取证”的原创组合，形成自己的识别度。
